How free mode works

TenSeconds AI sends your prompt to the public LTX-Video demo hosted by Hugging Face. It uses shared community GPU capacity, so it may queue, fail, or be paused. You can optionally add a free Hugging Face read token on your server for better access, but no paid video API is required. This prototype does not promise unlimited usage.
